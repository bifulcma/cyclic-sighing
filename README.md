# Sospiro ciclico

Guida alla respirazione *cyclic sighing* (Balban et al., *Cell Reports Medicine*, 2023): due inspirazioni dal naso, una lunga espirazione dalla bocca, cinque minuti al giorno.

Un solo file, `index.html`: niente dipendenze, niente backend. Il diario resta nel browser (localStorage).

Prima del respiro, un «Pensiero della notte» diverso ogni giorno: fonti e verifiche in `docs/FONTI.md`, test con `node test/pensieri.test.js`.

Apri: https://raw.githack.com/bifulcma/cyclic-sighing/main/index.html

Non sostituisce il parere di un medico.
